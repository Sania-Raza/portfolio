# Sania Raza Portfolio - React

## Run locally

```bash
npm install
npm run dev
```

## Add projects

Edit `src/data/projects.js`.

## Add LinkedIn articles

Edit `src/data/articles.js`:

```js
{
  title: "My Article",
  description: "Short description.",
  link: "https://www.linkedin.com/pulse/..."
}
```

## Build

```bash
npm run build
```
